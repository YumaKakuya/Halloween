# Candy Costume Workshop / おかし仮装工房

お菓子のパーツでハロウィンの仮装をつくり、画像を保存したりXでシェアしたりできるWebアプリです。

- 英語版（メイン）：`/`
- 日本語版：`/ja/`

このリポジトリはVercelにつながっていて、`main` にプッシュすると自動で公開されます。

## Xでのシェアの仕組み

「Share on X」を押すと、投稿文と `/c?hat=…&face=…` という仮装つきのリンクが入ったXの投稿画面が開きます（スマホではXアプリが開きます）。

Xがこのリンクを読みに来ると、`api/share.js` がその仮装専用のカード設定を返し、`api/og.js` がその仮装の画像（1200×630）をその場で描きます。投稿には、作った仮装がそのままカードとして大きく表示されるので、画像を手で添付する必要はありません。

リンクを開いた人には、同じ仮装の状態でアプリが表示されます。

## ファイル

| パス | 内容 |
|---|---|
| `src/index.html` | 英語版のページ |
| `src/ja/index.html` | 日本語版のページ |
| `src/costume.js` | 仮装の描画（ブラウザとカード画像生成で共通） |
| `src/app.js` | 画面の操作・保存・シェア |
| `src/style.css` | 見た目 |
| `src/og-en.png` / `src/og-ja.png` | トップページのリンクを貼ったときのカード画像 |
| `src/favicon.svg` | タブのアイコン |
| `api/share.js` / `api/share-ja.js` | `/c` と `/ja/c`：仮装ごとのカード設定つきページ |
| `api/og.js` | `/api/og`：仮装ごとのカード画像 |
| `fonts/` | カード画像用のフォント（SIL Open Font License、`fonts/OFL.txt`） |
| `build.mjs` | 公開時に `src` を `dist` にコピーし、サイトのURLを埋め込むスクリプト |
| `vercel.json` | ビルド、`/c` の振り分け、関数の設定 |

文言や見た目を変えるときは `src` の中を編集します。`__SITE_URL__` は公開時に自動で置き換わるので、そのまま残してください。

## 確認のしかた

- 仮装カード：`https://（あなたのURL）/api/og?hat=witch&face=vampire&outfit=choco&prop=cane&bg=moon` を開くと、カード画像が表示されます。
- Xは一度読んだリンクのカードをしばらく覚えています。トップページのカードを試すときは、URLの末尾に `?v=2` などを付けて貼ってください（仮装リンクは組み合わせごとにURLが違うので不要です）。
