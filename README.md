# Candy Costume Workshop / おかし仮装工房

お菓子のパーツでハロウィンの仮装をつくり、画像を保存したりXでシェアしたりできるWebアプリです。

- 英語版（メイン）：`/`
- 日本語版：`/ja/`

## 公開のしかた

このフォルダの中身をそのままGitHubのリポジトリに入れて、Vercelにつなぐだけです。URLを書き換える作業はありません。Vercelが公開するときに、そのプロジェクトのURL（独自ドメインがあればそちら）をカード画像の設定に自動で入れます。

**すでにVercelにつないだリポジトリがある場合**
1. リポジトリの中のファイルをすべて削除する
2. このフォルダの中身（`src` フォルダ、`build.mjs`、`vercel.json`、`package.json`、`.gitignore`、`README.md`）をアップロードしてコミットする
3. Vercelが自動で公開し直すのを待つ

**新しく始める場合**
1. GitHubで新しいリポジトリを作り、このフォルダの中身をアップロードする
2. Vercelで「Add New → Project」からそのリポジトリを選び、何も変えずに「Deploy」

## ファイル

| パス | 内容 |
|---|---|
| `src/index.html` | 英語版のページ |
| `src/ja/index.html` | 日本語版のページ |
| `src/app.js` | 描画・保存・シェアの処理（両言語共通） |
| `src/style.css` | 見た目（両言語共通） |
| `src/og-en.png` / `src/og-ja.png` | Xにリンクを貼ったときのカード画像（1200×630） |
| `src/favicon.svg` | タブのアイコン |
| `build.mjs` | 公開時に `src` を `dist` にコピーし、サイトのURLを埋め込むスクリプト |
| `vercel.json` | Vercelに上のスクリプトを実行させる設定 |

文言や見た目を変えるときは `src` の中だけを編集してください。`__SITE_URL__` という文字は公開時に自動で置き換わるので、そのまま残しておきます。

## カード画像が出ないとき

1. ブラウザで `https://（あなたのURL）/og-en.png` を開き、画像が表示されるか確認する
2. Vercelのビルドログに `Built for https://...` と出ているか確認する。URLが違う、または出ていない場合は、Vercelの「Settings → Environment Variables」で `SITE_URL` に公開URL（例：`https://candy-costume-site.vercel.app`）を追加して公開し直す
3. Xは一度読んだリンクのカードをしばらく覚えています。試すときはURLの末尾に `?v=2` などを付けて貼る

## シェアの動き

- **スマホ**：「Share on X」で共有シートが開き、仮装画像と投稿文をそのままXアプリに渡せます。
- **パソコン**：画像がダウンロードされ、投稿文入りのXの投稿画面が開きます。画像は投稿時に添付してください。
- 投稿に入るリンクには仮装の組み合わせが含まれていて、開いた人には同じ仮装が表示されます。
